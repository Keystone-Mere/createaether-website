# Create Aether Website

The public website and browser-based MVP for Aether, a modular experience engine for composing immersive digital atmospheres.

## Current MVP

The Studio currently provides:

- Five experience presets: Temple, Forest, Ocean, Christmas and Storm
- Controllable audio and volume
- Lighting, fog and particle controls
- Live browser previews
- Local browser storage for saved configurations
- JSON-based experience definitions

Marketplace, publishing, account services and a public SDK remain planned.

## Technology

- Astro
- TypeScript
- HTML Canvas
- CSS
- Cloudflare Pages
- Sentry
- PostHog
- Auth0
